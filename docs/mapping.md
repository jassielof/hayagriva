# Mapping documentation

Currently, Hayagriva is only able to convert from Bib(La)TeX to Hayagriva as a unidirectional mapping. To help with it, this document serves as a mapping reference for the library to follow instea of being hardcoded in the codebase as documentation comments, this will also help for non-technical users to review what the library implements without reading the source code, and also to figure out a bidirectional mapping.
